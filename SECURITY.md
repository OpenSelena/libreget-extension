# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| < 0.4   | No        |

## Reporting a Vulnerability

Do not open public GitHub issues for security bugs.

Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/OpenSelena/libreget-extension/security/advisories/new) or email **igect@vk.com**.

Please include:
- Steps to reproduce
- Affected browser and version
- Proof of concept (redact any personal cookies or private URLs from logs)

We will acknowledge reports within 48 hours and work on a fix before any public disclosure.
